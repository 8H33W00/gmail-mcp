Privacy Policy

Last updated: 2026-10-12

Claude Gmail MCP is a personal tool used only by its owner (tigerson95@gmail.com) on the owner's own computer.

Data accessed

With the owner's consent through Google OAuth, the tool reads, searches and labels messages in the owner's own Gmail account.

Storage and sharing

OAuth tokens are stored only on the owner's local computer. Email data is not collected by any server operated for this tool, is not sold, and is not shared with third parties. Data is used only to answer the owner's own requests.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
